THE 100% PURE CSS ENGINE

Each Pixel Miner is generated as an independent, ultra-lightweight HTML document. The animated pixels are drawn purely with CSS cascading box-shadows.

📐
24x24 ASCII Discrete Grid:

Pixels are defined using container query units (`3.125cqw`) allowing lossless scaling to 4K displays with sharp pixel clarity.

⚡
Zero JavaScript Execution:

Deterministic 100ms keyframe transitions (`steps(N)`) run on the browser compositor with 0 CPU strain.

🔒
3D Euclidean Contrast Rules:

RGB Euclidean distance checks ensure chassis, strata, trims, and ores always maintain high contrast.

FREQUENTLY ASKED QUESTIONS

How many Pixel Miners exist in total?

There are exactly 10,000 unique Pixel Miners (Token #1 to #10,000). The collection is strictly capped and deterministically generated.

What makes the pure HTML+CSS engine unique?

Instead of heavy raster PNGs or GIFs, each token is a standalone HTML document. The animated pixels are drawn purely by cascading CSS box-shadows, ensuring permanent, lightweight on-chain rendering on IPFS and web browsers.

How is visual uniqueness ensured?

Every token's combination of 13 attributes (Tool, Mod, Optic, Pack, Undercarriage, Chassis, Trim, Glass, Panel, Strata, Ore, Wear, Rarity) is verified for 100% uniqueness with 0 duplicate visual signatures in the entire supply.
